= Mutiny Vert.x bindings documentation

The documentation is AsciiDoc, laid out like the Quarkus guides, and published on
https://smallrye.io/docs/smallrye-mutiny-vertx-bindings/latest/[smallrye.io]. The site pulls it from this
repository: the `main` branch every night, and each release once it is tagged.

== Where things are

[cols="1,2"]
|===
|`src/main/asciidoc/*.adoc` |One page per file. The file name is the page's address: `getting-started.adoc` is published at `/docs/smallrye-mutiny-vertx-bindings/<version>/getting-started/`.
|`src/main/asciidoc/_nav.yml` |The sidebar: page order and sections. A new page must be added here.
|`src/main/asciidoc/_attributes.adoc` |Attributes every page includes (ids, `examples-dir`, project values).
|`src/main/asciidoc/compatibility-report-3-to-4.adoc` |Generated by `just compatibility-report` (Revapi), from `target/compatibility-report.adoc`.
|===

== Writing a page

[source,asciidoc]
------
= Page title
include::_attributes.adoc[]
:summary: One sentence for search engines and the page description.

Text...

== A section

Link to another page with xref:error-handling.adoc[Error handling], or to a section of it with
xref:error-handling.adoc#a-section[].

[.tabs]
====
Mutiny::
+
--
[source,java]
----
Uni<JsonObject> body = client.get("/api").send().onItem().transform(HttpResponse::body);
----
--
Vert.x::
+
--
[source,java]
----
Future<JsonObject> body = client.get("/api").send().map(HttpResponse::body);
----
--
====
------

* An example block with the `tabs` role holding a labelled list is shown as tabs on the site.
* Section ids are Quarkus-style: `== Type Mapping` gets the id `type-mapping`.
* Include part of an example by marking it with `// tag::example[]` and `// end::example[]`, then `[tags=example]`.
* Admonitions: `NOTE:`, `TIP:`, `IMPORTANT:`, `WARNING:`, `CAUTION:`.

== Previewing

Pull requests that change the documentation are rendered with the smallrye.io site by the
`Documentation` workflow, which fails on a broken include or a page that does not render. The
rendered site is attached to the workflow run as the `docs-smallrye-mutiny-vertx-bindings` artifact.

To see the documentation the way smallrye.io shows it while you write it, run from this repository:

[source,bash]
----
./mvnw -Pdocs-preview
----

and open http://localhost:8080/docs/smallrye-mutiny-vertx-bindings/main/. Pages and included examples are published again
when you save them; refresh the page. Only Java is needed: the profile runs the
https://github.com/smallrye/smallrye.github.io/tree/develop/tools/docs[smallrye.io docs tools]
with https://www.jbang.dev[JBang]. Where JBang is installed, `jbang docs-preview@smallrye/smallrye.github.io`
does the same, and takes options such as `--port` or `--site <a smallrye.github.io checkout>`
(see `--help`).
